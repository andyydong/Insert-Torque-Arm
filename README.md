# Torque-Arm

## What is this project
This is a custom adjustable torque arm base. Basically, it's a torque arm that is mostly 3D-printed and is intended to help you with tool use. It uses a spring to keep the tool wherever you leave it. This is adjustable for whatever tool you are using. It is intended to be used with custom fixtures for whatever tool you want to use with it. 

## Why did I make this
I wanted to make this torque arm so that you can use your tools more effectively, get more consistent results, and reduce fatigue from using tools. It features adjustable tension so that it can counterbalance a variety of tools of different weights. Its design is not specific to any tool, so that you can mount any tool with a custom fixture for your tool.

## How does it work
It uses a double four-bar linkage system to better counterbalance your tool weight and also to increase extension length. It also features an adjustable lead screw that changes the tension on the spring to allow it to adapt to any weight. 

### Assembly
- Calipers are highly recommended
- Look at the Onshape assembly to assist
- m4, m5 screws and brass inserts are required

Instructions
- Follow the Onshape assembly
- Assemble the arms with the lead screw first
- Then assemble the other arms
- Attach arms to the triangular plates
- Attach both sets of arms to the trapezoid mid plate
- Attach springs to plates and lead screw nuts by taking the ring of the extension spring, putting it through the bolt and screwing it down
